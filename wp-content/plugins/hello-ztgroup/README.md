# Hello ZTGroup Plugin

Plugin de ejemplo para demostrar el flujo completo de deployment con Git.

## Características

- Muestra un mensaje de bienvenida en el dashboard de WordPress
- Página de administración con información del sistema
- Ejemplo de hooks de activación/desactivación
- Compatible con WordPress Multisitio

## Instalación

Este plugin se instala automáticamente mediante el sistema de deployment con Git.

## Uso

1. Activa el plugin desde el panel de WordPress
2. Verás un mensaje de bienvenida en el dashboard
3. Accede al menú "Hello ZTGroup" en el admin para ver más detalles

## Versión

**1.0.0** - Versión inicial de ejemplo

## Desarrollo

Este plugin forma parte del sistema de deployment documentado en el repositorio principal.

### Flujo de Deployment

```
Local → GitHub → Staging → Producción
```
